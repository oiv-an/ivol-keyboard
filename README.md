# IVOL Keyboard

Клавиатура для Android с офлайн-распознаванием речи (GigaAM от Сбера или Fluid Speech Pro), офлайн-переводом и
«волшебной палочкой» — правкой текста нейросетью через твой собственный сервер.
Основана на клавиатуре Android Open Source Project (LatinIME), Apache-2.0.

По умолчанию включены русский и английский, остальные языки (польский, украинский, венгерский
и ещё ~75) включаются в настройках. Распознавание речи и обычный перевод работают на самом телефоне,
без отправки текста и звука на сервер. В сеть уходит только то, что ты сам отправил
волшебной палочкой, и только на сервер, который ты указал.

## Скачать

Готовый APK лежит в разделе
[Releases](https://github.com/oiv-an/ivol-keyboard/releases/latest) — скачай файл
`ivol-keyboard-<версия>.apk` на телефон и открой его. Android спросит разрешение на установку
приложений из этого источника, затем клавиатуру нужно включить в настройках
(«Язык и ввод» → «Экранная клавиатура») и выбрать как основную.

Нужен Android 7.0 или новее, процессор arm64 (все современные телефоны).
APK подписан ключом разработчика; обновления ставятся поверх предыдущей версии.

### Обновления

**С версии 0.3.0 клавиатура обновляется сама.** Раз в день, пока ты печатаешь, она смотрит
[последний релиз](https://github.com/oiv-an/ivol-keyboard/releases/latest) на GitHub. Если вышла
новая версия, справа на верхней панели появляется значок обновления. Нажал — APK скачивается,
проверяются контрольная сумма SHA-256, номер версии и подпись, и открывается системная установка.
Без нажатия ничего не скачивается и не ставится. Один раз Android попросит разрешить
клавиатуре устанавливать приложения. В настройках («Обновления») можно выключить проверку
или запустить её вручную.

Все дальнейшие улучшения выходят только в версиях с автообновлением.
**Если нужна версия без автообновления**, бери
[0.2.1](https://github.com/oiv-an/ivol-keyboard/releases/tag/v0.2.1) — это последняя такая версия.

## Возможности

- **Голосовой ввод офлайн.** Отдельная кнопка микрофона справа от пробела: нажал, держишь,
  говоришь, отпустил. Текст пишется по ходу речи, со знаками препинания. Модель выбирается
  в настройках («Голосовой ввод»), обе работают через [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx):
  - [GigaAM v3](https://huggingface.co/csukuangfj/sherpa-onnx-nemo-transducer-punct-giga-am-v3-russian-2025-12-16)
    (Сбер) — только русский, ~230 МБ, быстрая;
  - [Fluid Speech Pro](https://huggingface.co/FluidVoice-Labs/fluid-speech-pro-onnx) (int8) —
    25 европейских языков, ~800 МБ, точнее, но тяжелее.

  Ненужную модель можно удалить кнопкой «Удалить», чтобы не занимала место.
- **Волшебная палочка (нейросеть).** Нажатие на палочку прямо в верхней строке заменяет иконки
  на три действия:
  - «Оформить» — орфография, пунктуация, регистр без изменения смысла;
  - «Переписать» — тот же смысл, но понятнее и аккуратнее;
  - «Перевести через модель» — русский → английский, остальное → русский.

  Действие применяется к выделенному тексту или ко всему полю. Повторное нажатие того же
  действия возвращает исходный текст. Повторное нажатие на палочку возвращает обычные иконки,
  долгое — открывает её настройки.
- **Логотип слева** всегда возвращает панель инструментов, даже когда в строке висят подсказки
  слов. Удобно после диктовки: логотип → палочка → «Оформить».
- **Своя модель.** В настройках («Подключение модели») указываешь сервер в формате OpenAI
  (например `https://api.openai.com/v1`) и ключ, выбираешь модель из списка, который отдаёт
  сервер (`/models`), и уровень размышлений (`reasoning_effort`). У каждой кнопки палочки свой
  промт — его можно переписать под себя или вернуть по умолчанию. Ключ хранится только на
  телефоне.
- **Языки.** Настройки → «Языки» → «+ Добавить язык». Раскладки всех языков уже внутри APK,
  а словарь подсказок нужного языка скачивается при включении с GitHub (релиз
  [`dicts-v1`](https://github.com/oiv-an/ivol-keyboard/releases/tag/dicts-v1), проверка SHA-256),
  поэтому приложение не растёт. Глобус переключает только включённые языки.
- **Перевод офлайн.** Кнопка 文A переводит выделенный текст или всё поле целиком. Если включены
  только русский и английский — направление определяется автоматически. Если включено больше
  языков — на панели появляются кнопки языков (RU, EN, PL, UA…), язык исходного текста
  определяется сам. Повторное нажатие возвращает исходный текст. Словарь перевода
  (Google ML Kit, ~30 МБ на язык) скачивается один раз при первом переводе на этот язык.
- **Буфер обмена.** Как в Яндексе: скопировал текст в другом приложении — кнопка буфера
  на панели подсвечивается, одно нажатие сразу вставляет (подсветка держится 5 минут).
  Иначе кнопка (или долгое нажатие на неё) открывает последние 10 скопированных
  фрагментов: нажатие вставляет, долгое нажатие удаляет.
- **Подсказки слов** для всех включённых языков, запоминание часто используемых слов.
- **Автоисправление как в Яндексе.** Слово с опечаткой исправляется по пробелу; нажатие
  «стереть» сразу после этого возвращает слово, как ты его набрал. Слитные слова
  разделяются: «тотже» или «тотбже» → «тот же».
- **Настройки внешнего вида** с живым предпросмотром: высота клавиатуры, ширина клавиш,
  скругление углов, вибрация и её сила.
- Тёмная тема, подсказки символов на клавишах, всплывающие меню по долгому нажатию, эмодзи.

## Сборка

Нужны JDK 17, Android SDK (API 36), NDK 28 и CMake.

```sh
# 1. Скачать AAR библиотеки sherpa-onnx (52 МБ, в репозиторий не входит)
./tools/fetch-sherpa-onnx.sh

# 2. Указать путь к Android SDK
echo "sdk.dir=/путь/к/android-sdk" > local.properties

# 3. Собрать
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

### Сервер нейросети по умолчанию (необязательно)

Чтобы сборка сразу знала твой сервер для волшебной палочки, создай файл `ai-dev.properties`
в корне (он в `.gitignore`, ключ в репозиторий не попадёт):

```properties
ivol.ai.baseUrl=https://api.openai.com/v1
ivol.ai.apiKey=sk-...
ivol.ai.model=gpt-6.1-sol
ivol.ai.reasoning=
```

Значения подставляются в настройки один раз, при первом запуске. Без этого файла настройки
нейросети пустые, их заполняешь в приложении.

### Релизная сборка

Для подписанного релиза положи в корень файл `key.properties` (он в `.gitignore`):

```properties
storeFile=/путь/к/ключу.jks
storePassword=...
keyAlias=...
keyPassword=...
```

```sh
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

Без этого файла релизная сборка останется неподписанной. Настройки нейросети в релизной
сборке всегда пустые — `ai-dev.properties` подставляется только в debug.

## Установка через adb

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Затем включи клавиатуру в настройках Android («Язык и ввод» → «Экранная клавиатура»)
и выбери её как основную. Через adb это же делается так:

```sh
adb shell ime enable pro.ivol.keyboard.debug/com.android.inputmethod.latin.LatinIME
adb shell ime set pro.ivol.keyboard.debug/com.android.inputmethod.latin.LatinIME
```

## Модель распознавания речи

Модели не входят в APK. Выбранная модель скачивается при первом нажатии на микрофон или
кнопкой «Скачать» в настройках: GigaAM — в `files/gigaam/`, Fluid Speech Pro — в `files/fluid/`.
Дальше распознавание работает без интернета. Скачивание продолжается после обрыва, каждый
файл проверяется по размеру и SHA-256. GigaAM можно положить заранее вручную:

```sh
# файлы encoder.int8.onnx, decoder.onnx, joiner.onnx, tokens.txt из репозитория модели
MODEL=sherpa-onnx-nemo-transducer-punct-giga-am-v3-russian-2025-12-16
adb push "$MODEL" /data/local/tmp/
adb shell run-as pro.ivol.keyboard.debug sh -c \
  "mkdir -p files/gigaam && cp -r /data/local/tmp/$MODEL files/gigaam/ && echo ok > files/gigaam/$MODEL/.installed"
```

Для микрофона нужно разрешение на запись звука, клавиатура попросит его сама.

## Что изменено по сравнению с AOSP

Основной код клавиатуры взят из AOSP LatinIME. Свой код лежит в
`app/src/main/java/com/android/inputmethod/latin/ivol/`:

| Файл                                           | Назначение                                   |
| ---------------------------------------------- | -------------------------------------------- |
| `GigaAmVoice.kt`                               | загрузка модели, запись звука, распознавание |
| `IvolAi.kt`, `IvolAiPrefs.kt`                  | запросы к серверу OpenAI, настройки и промты |
| `IvolTranslator.kt`                            | перевод через ML Kit                         |
| `IvolLanguages.kt`                             | включённые языки, загрузка словарей          |
| `ClipboardHistory.kt`, `ClipboardPanelView.kt` | история буфера обмена                        |
| `IvolSettingsActivity.kt`, `IvolPrefs.kt`      | экран настроек и его значения                |
| `MicPermissionActivity.kt`                     | запрос разрешения на микрофон                |

Остальные правки в файлах AOSP помечены комментарием `IVOL:`. Внешний вид задан в
`res/values/colors-ivol.xml`, `dimens-ivol.xml` и `res/drawable/ivol_*`.
